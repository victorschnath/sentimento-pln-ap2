# Análise de sentimento com PLN

Ambiente utilizado: Python 3.14.6.

Para instalar as dependências e executar no Windows, abra o terminal na pasta do projeto:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Nesta etapa, o programa gera `resultados/exploracao.txt`.
